# SDL IGR
A template for adding simple in-game reset to your SDL2 or SDL3 commands, using Cerbios bindings first and a fallback quick reset using ```LT+RT+Start+Back```. Simply include IGR_SDL2.h or IGR_SDL3.h in your project, call it in your input loop, and now when you press any of your Cerbios IGR bindings, your system will reset exactly as it would in a retail Xbox / XDK-based game.
